# 늘곁 시연 가이드

## 준비

```bash
npm install
npm run dev          # http://localhost:3000 — 첫 실행 시 가상 데이터 자동 생성
```

데이터를 처음 상태로 되돌리려면 서버를 멈추고 `npm run db:reset`.

## 가상 계정 (`/login`에서 선택)

| 계정 | 역할 | 보이는 범위 |
|---|---|---|
| 늘봄시 관리자(가상) `U-ADMIN` | 지자체 관리자 | 전 지역, 감사 로그 |
| 해솔구 담당자 A(가상) `U-W1` | 돌봄 담당자 | 해솔구 — 시나리오 대상자 대부분 담당 |
| 다온구 담당자 B / 미르구 담당자 C·D | 돌봄 담당자 | 각 구 |
| 해솔 나눔도시락센터 담당자 `U-P1` | 기관 담당자 | 자기 기관 의뢰만 |
| NG-0007 본인 `U-R7` / 가족 `U-F7` | 대상자·가족 | 포털 |
| 동의 철회 가족 `U-F9` | 가족 | 아무것도 볼 수 없음 (철회 확인용) |

## 시나리오 대상자

| 시나리오 | 대상자 | 보여 줄 것 |
|---|---|---|
| A 정상 | NG-0001 | 분석 결과 "신호 없음" — 불필요한 경고를 만들지 않음 |
| B 미완료 방문 | NG-0002 | R1·R2 신호, 근거 기록 REC 링크 |
| C 서비스 공백 | NG-0003 | 방문 돌봄 중단 12일 → 대체 서비스 후보 → 의뢰 |
| D 조치 지연 | NG-0004 | 기한 경과 조치 2건, 담당자·지연 표시 |
| E 지역 공백 | 미르구 별빛동 | 지도에서 미연계 사례 집중 |
| F 조치 완료 | NG-0006 | 분석 검토 조치 완료 → 대시보드 완료율 변화 |
| G 가족 문의 | NG-0007 / `U-F7` | 포털에서 서비스·일정 확인, 문의 등록 → 담당자 답변 |
| H 음성 기록 | NG-0008 | 음성 또는 직접 입력 → 초안 → 수정 → 저장 |

## 3분 시연 순서

1. **(20초)** `U-ADMIN` 로그인 → 지역 대시보드: KPI와 지역별 현황(모든 수치는 DB 집계)
2. **(30초)** 통합 돌봄 지도 → 별빛동 선택: 미연계 34건, 자원 부족, 대상자 목록 연동 (시나리오 E)
3. **(40초)** 로그아웃 → `U-W1` → 위험 신호 분석 → NG-0002: 규칙별 이유, 근거 기록 링크, "점수는 확률이 아님" 표기 → 수정 후 수용 + 조치 등록 (B)
4. **(40초)** NG-0003 서비스 연계 탭 → 후보 찾기: 추천 이유·미확인 조건 → 검토 체크 → 의뢰 생성 (C)
5. **(20초)** 후속 조치 → 방금 만든 조치 완료(결과 입력) → 대시보드 완료율 변화 확인 (F)
6. **(20초)** 음성 기록 → 마이크 또는 직접 입력 → 규칙 기반 초안 → 수정 → 저장 (H)
7. **(10초)** `U-F7` 포털: 큰 글씨, 쉬운 상태, 내부 메모 없음 → 문의 보내기 (G)

## 예상 문제와 대체 시나리오

| 상황 | 대응 |
|---|---|
| 브라우저가 음성 인식을 지원하지 않음 (Firefox/Safari 일부) | 화면이 자동으로 안내 — 텍스트 직접 입력으로 같은 흐름 시연 |
| 마이크 권한 거부 | 오류 안내 후 직접 입력 |
| AI 키 없음 | "AI 미설정" 표시가 정상 동작. 규칙 기반 분석·템플릿 보고서로 시연 |
| 데이터가 시연 중 바뀜 | 서버 정지 후 `npm run db:reset` |
| 날짜가 지나 기한 표시가 달라짐 | 시드는 실행 시점 기준 상대 날짜 — `db:reset`으로 새로 생성 |
| 서버 배포 환경(Vercel) | PGlite 데이터가 `/tmp`에 있어 인스턴스 재시작 시 초기화됨. 시연용으로는 무방, 운영은 PostgreSQL 필요 |
| 포트 충돌 | `npm run dev -- -p 3001` |
