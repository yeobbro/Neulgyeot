## 실행하지 못한 테스트

- **실제 AI API 호출** — 이 환경에 `ANTHROPIC_API_KEY`가 없음. 대체 생성 함수로만 검증
- **실제 마이크 음성 인식** — 헤드리스 브라우저에 마이크·Web Speech 서버가 없음. 미지원 안내와 직접 입력 경로만 확인
- **운영 PostgreSQL** — PostgreSQL 서버가 없어 PGlite로만 실행 (같은 SQL)
- **스크린리더 실사용 테스트** — 의미 구조·aria 속성은 넣었지만 NVDA/VoiceOver로 직접 확인하지 않음
- **부하·동시성 테스트**
- **GitHub Actions CI 실행** — 워크플로는 수정했지만 이 세션에서 원격 CI 결과는 확인하지 않음
