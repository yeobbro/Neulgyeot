# Brand migration: GARDEN by GADO → Neulgyeot

## Decision

The product's working brand is **Neulgyeot (늘곁)**. The parent product studio is **KREWX**. New code, filenames, documentation, UI copy, and product links should use Neulgyeot unless they are explicitly describing historical source material.

## Product definition carried forward

Neulgyeot is an AI care-intelligence platform intended to help care workers and social workers notice meaningful changes in a person's usual pattern, understand the evidence behind those changes, and decide whom to check first. Intended settings include care facilities, home-based care, community care, and municipal welfare services.

The core idea is retained from the previous project:
- compare observations with an individual's usual baseline;
- highlight changes across daily care and lifestyle records;
- show evidence and time context, not a black-box score alone;
- make suggestions such as "확인 권장" or "관찰 권장";
- keep the care professional in control.

## Migration policy

1. Keep the original GARDEN by GADO files untouched as historical source material.
2. Use new Neulgyeot-named copies for current planning and communication.
3. Do not copy old concept/mockup screens into the live prototype as if they were actual working features.
4. Keep public product status honest: the current site is an early prototype using synthetic data.
5. Do not preserve GADO as the company name or show the former brand in new public-facing pages.

## Non-goals for the current prototype

Neulgyeot is not a medical diagnosis product, not an emergency prediction product, not a care-worker replacement, and not an automated decision-maker. Real personal data must not be used in this prototype.
